# Mariia Play — живые сцены для дошкольников

Проект: взрослый и ребёнок придумывают тему и сценарий, агент собирает из этого живую интерактивную сцену. Цель — сделать максимально близко к описанию ребёнка.

Личные подробности об игроке — в `CLAUDE.local.md` (не в git).

## Игрок (общие требования)
- Дошкольник, не читает → в интерфейсе **никакого текста**: только иконки, звуки, анимация.
- Ноутбук с тачпадом и планшет → крупные цели для клика (≥ 60px), без клавиатуры. Основное — тапы; перетаскивание (drag) можно, но только для крупных объектов и с подсветкой цели. Pointer events, `touch-action: none`.
- Без страшных элементов, без проигрыша, без таймеров и штрафов. Скорее «живая сцена», чем игра с целью.

## Формат
- Стиль: 2D или изометрия, как детские обучающие игры. По умолчанию Canvas 2D, вся графика рисуется кодом (векторно-мультяшная).
- Звук: WebAudio-синтез, без файлов (`src/core/audio.ts`). Стартовый экран с большой кнопкой ▶ (разблокирует звук). Маленькая кнопка выкл. звука для взрослого.
- Адаптивность: масштаб `S = min(W,H)/720`, работает и в альбомной, и в портретной ориентации.

## Устройство проекта (Vite + TypeScript)
- `index.html` — витрина сцен (без текста: большие круглые картинки из `public/thumbs/`).
- `<сцена>/index.html` — HTML-оболочка сцены (canvas `#c`, стартовая кнопка), подключает `src/scenes/<сцена>/main.ts`.
- `src/core/` — общее для всех сцен: `canvas.ts` (холст, W/H/S/BR, время `t`, rand/clamp/…, pointer), `audio.ts`, `draw.ts` (фигуры, кнопка), `particles.ts`.
- `src/scenes/<сцена>/` — код сцены, разбитый по смыслу. Общее изменяемое состояние сцены — объект `G` в `state.ts` (scene, curHouse, drag, night…); `W/H/S/t` меняются только в `core/canvas.ts`.
- TypeScript в мягком режиме (`strict: false`); главное — `npm run typecheck` ловит опечатки и забытые импорты.
- Новая сцена: папка `<сцена>/index.html` + `src/scenes/<сцена>/main.ts`, добавить страницу в `scripts/pages.mjs`, ссылку и картинку в витрину, тест в `tests/`.
- Движки (Phaser/Pixi) не подключены; можно добавить позже для отдельной сцены через npm.

## Команды
- `npm run dev` — разработка, http://localhost:5173 (страница обновляется сама).
- `npm run build` — typecheck + сборка в `dist/`: каждая страница — один самодостаточный HTML (vite-plugin-singlefile), открывается и двойным кликом, и с GitHub Pages.
- `npm test` — Playwright: собирает, поднимает preview и гоняет сценарии (`tests/*.spec.ts`) через `window.__game` (`step(sec)` мгновенно крутит симуляцию, `api.*` — действия игрока). Скриншоты — в `test-results/shots/`, их нужно смотреть глазами.
- Деплой: push в `main` → GitHub Actions (`.github/workflows/pages.yml`) гоняет тесты и публикует `dist` на GitHub Pages.

## Наполнение
- ~3 основные механики (повторяемые действия, на которые мир отвечает заметно).
- 5–10 мини-интеракций (ткнул — что-то мило отреагировало; персонажи моргают, следят глазами, машут; искорки за курсором).
- Любой клик куда угодно должен что-то давать — пустых мест нет.

## Процесс
1. Записать идею ребёнка в «карточку сцены»: герои, мир, 3 механики, мини-интеракции. Взрослый зачитывает, ребёнок правит.
2. Быстро собрать первую играбельную версию.
3. Круги правок «что поменять/добавить».
4. Перед сдачей — `npm run typecheck` и `npm test` (сценарий на новую механику добавить в тест), посмотреть скриншоты из `test-results/shots/`.
5. Коммит в git с понятным описанием; push в `main` публикует на Pages.

## Сцены
- `babies-in-space/` — «Малыши в космосе»: космос с малышами; здания (ясли с кроватками и большими игрушками, столовая со стульчиками и едой) — кнопка домика открывает выбор здания; у малышей появляются желания (спать/играть/есть), исполненное желание — анимация восторга; тапы по малышу и планете — 3 реакции по кругу.
