# Mariia Play — живые сцены для дошкольников

Проект: взрослый и ребёнок придумывают тему и сценарий, агент собирает из этого живую интерактивную сцену. Цель — сделать максимально близко к описанию ребёнка.

Личные подробности об игроке — в `CLAUDE.local.md` (не в git).

## Игрок (общие требования)
- Дошкольник, не читает → в интерфейсе **никакого текста**: только иконки, звуки, анимация.
- Ноутбук с тачпадом и планшет → крупные цели для клика (≥ 60px), без клавиатуры. Основное — тапы; перетаскивание (drag) можно, но только для крупных объектов и с подсветкой цели. Pointer events, `touch-action: none`.
- Без страшных элементов, без проигрыша, без таймеров и штрафов. Скорее «живая сцена», чем игра с целью.

## Формат
- Стиль: 2D или изометрия, как детские обучающие игры. По умолчанию Canvas 2D, вся графика рисуется кодом (векторно-мультяшная).
- Звук: WebAudio-синтез, без файлов (`src/core/audio.ts`). Стартовый экран с большой кнопкой ▶ (разблокирует звук). Маленькая кнопка выкл. звука для взрослого.
- Адаптивность: масштаб `S = min(W,H)/720`, работает и в альбомной, и в портретной ориентации.
- **Главная платформа — телефон.** Ориентир — будущее мобильное приложение; уже сейчас основной запуск — с телефона, с ярлыка на домашнем экране (PWA, `display: standalone`, safe area). Портрет на телефоне — главный кейс: всё проверять в нём в первую очередь, ноутбук и планшет — вторичны.

## Устройство проекта (Vite + TypeScript)
- `index.html` — витрина сцен (без текста: большие круглые картинки из `public/thumbs/`).
- `<сцена>/index.html` — HTML-оболочка сцены (canvas `#c`, стартовая кнопка), подключает `src/scenes/<сцена>/main.ts`.
- `src/core/` — общее для всех сцен: `canvas.ts` (холст, W/H/S/BR, время `t`, rand/clamp/…, pointer), `audio.ts`, `draw.ts` (фигуры, кнопка), `particles.ts`.
- `src/scenes/<сцена>/` — код сцены, разбитый по смыслу. Общее изменяемое состояние сцены — объект `G` в `state.ts` (scene, curHouse, drag, night…); `W/H/S/t` меняются только в `core/canvas.ts`.
- TypeScript в мягком режиме (`strict: false`); главное — `npm run typecheck` ловит опечатки и забытые импорты.
- Новая сцена: папка `<сцена>/index.html` + `src/scenes/<сцена>/main.ts`, добавить страницу в `scripts/pages.mjs`, ссылку и картинку в витрину, тест в `tests/`.
- Движки (Phaser/Pixi) не подключены; можно добавить позже для отдельной сцены через npm.

## Команды
- `npm run dev` — разработка, http://localhost:5173 (страница обновляется сама).
- `npm run build` — typecheck + сборка в `dist/`: каждая страница — один самодостаточный HTML (vite-plugin-singlefile), открывается и двойным кликом, и с GitHub Pages.
- `npm test` — Playwright: собирает, поднимает preview и гоняет сценарии (`tests/*.spec.ts`) через `window.__game` (`step(sec)` мгновенно крутит симуляцию, `api.*` — действия игрока). Скриншоты — в `test-results/shots/`, их нужно смотреть глазами.
- Деплой: push в `main` → GitHub Actions (`.github/workflows/pages.yml`) гоняет тесты и публикует `dist` на GitHub Pages.

## Наполнение
- ~3 основные механики (повторяемые действия, на которые мир отвечает заметно).
- 5–10 мини-интеракций (ткнул — что-то мило отреагировало; персонажи моргают, следят глазами, машут; искорки за курсором).
- Любой клик куда угодно должен что-то давать — пустых мест нет.

## Процесс
0. Идеи, решения и исследования агентов не терять: бэклог — `docs/IDEAS.md`, отчёты и эскизы агентов — `docs/research/<дата-тема>/`.
1. Записать идею ребёнка в «карточку сцены»: герои, мир, 3 механики, мини-интеракции. Взрослый зачитывает, ребёнок правит.
2. Быстро собрать первую играбельную версию.
3. Круги правок «что поменять/добавить».
4. Перед сдачей — `npm run typecheck` и `npm test` (сценарий на новую механику добавить в тест), посмотреть скриншоты из `test-results/shots/`.
5. Коммит в git с понятным описанием; push в `main` публикует на Pages.

## Сцены
- `babies-in-space/` — «Малыши в космосе»: космос с малышами; здания — по одному каждого вида (ясли с кроватками и большими игрушками, столовая со стульчиками и едой, ванная с ванной и горшками) — кнопка домика открывает выбор ещё не построенных зданий, выбранная кнопка улетает в космос и превращается в здание; кнопка-ракета раскрывает дугой веер выбора малыша (`babypick.ts`): скафандр, пузырь, тарелка, ракета и «?» (случайный вид); в кнопках живые превью (моргают, следят за пальцем) — тап, и именно этот малыш выпрыгивает из кнопки в космос, на его месте новый; веер не закрывается, чтобы запускать подряд, закрывается ракетой, тапом мимо, домиком или на 17 малышах; малыш на луне — единственный, в выборе его нет; планета — тоже место, как дом (`park.ts`): малыша кладут на планету — он на детской площадке, на макушке планеты по её изгибу стоят ворота-радуга, мини-качели и горка — тап по ним: камера «ныряет» к воротам и мы на площадке (тап по лицу — прежние реакции); над планетой и над каждым зданием — сердечко за каждого малыша внутри; малыши без желания сами ходят играть на свободные места, наигравшись — слезают; на площадке качели на двоих (качаются вперёд-назад: сиденье ближе — крупнее; тап — раскачать), горка (малыш съезжает и сам лезет обратно до 3 раз), песочница на двоих (лепит куличики, тап — «пуф»), лужа (прыгает, пачкается — грязь смывает ванна, грязный чаще хочет купаться; тап — лягушонок), батут (тап — выше и кувырок; малыша в прыжке можно поймать), цветы, норка с соседом, наши дома в небе, ворота-радуга — назад в космос; у малышей появляются желания (гулять — на конкретное место площадки; спать; играть — в конкретную игрушку: лошадка/ксилофон/мяч/башня; есть — конкретную еду с подноса; а когда есть ванная — горшок/купаться), не та игрушка/еда — пузырь качается «не-а», желание остаётся; исполненное желание — анимация восторга; в ванной малыш после купания мокрый (капает), полотенце снимается с крючка, укутывает с капюшоном-ушками и вытирает; тапы по малышу и планете — 3 реакции по кругу.
- `heart-dress-up/` — «Сердечко-модница»: большое сердце с глазами украшается по этапам (цвет, глаза, рот — всегда есть по умолчанию; реснички, нос, щёчки, причёска, серёжки, ожерелье — можно «без этого»; окружение — можно несколько сразу; фон — цвет неба, один выбор; пейзаж — облака, радуга, солнце, холмы, луна, флажки, дерево, замок, море, несколько сразу). Сверху вниз: лента этапов в одну строку (свободный выбор, на узком экране листается), под ней панель вариантов — 2 ряда у нижнего края (портрет) или 3 справа от сердца (ландшафт, лента тогда сверху); варианты листаются вбок пальцем/тачпадом только если не влезают, под ними скроллбар; сердце занимает всё свободное место с учётом причёски; выбор срабатывает на отпускании, если палец не тянул ленту. По 8–10 непохожих вариантов в группе. У каждой детали своя реакция (звук + анимация, `reactions.ts`): при выборе и при тапе по надетой детали. После наряда на ленте — уход (`care/`, подробности ниже): еда, ванна, сон; и фото-альбом (фотоаппарат, тап по фото возвращает наряд). На ленте зелёная звёздочка — раздел украшен (палочкой), розовый кружок с сердечком — «моё», раздел выбран руками (`G.byHand`: ставится любым ручным выбором, включая «без этого» и повторный тап, снимается «заново», хранится в localStorage и в каждом фото альбома). Волшебная палочка (слева внизу) — случайный наряд, сердце крутится; палочка меняет только разделы без метки «моё» и «щёлкает» только меняемыми деталями; если руками выбрано всё — только радость (кружится, смеётся, сердечки, реакция одной из деталей), наряд не меняется. Наряд, собранный руками, перед «заново» и загрузкой фото сам уходит в альбом; фото из альбома возвращается со своими метками «моё». Кнопка-хлопушка (пульсирует, когда украшено ≥3 разделов) → праздник: сердце танцует под музыку, мини-сердечки водят хоровод, кнопки «заново», фотоаппарат и «украшать дальше». Окружение рисуется только в области сердца и обходит кнопки. Тапы по телу сердца — 3 реакции по кругу; малыши-сердечки, пузыри, бабочки, шарики, искорки, цветы, котёнок, рыбки, утёнок, солнце, луна, облака, радуга, холмы, флажки, дерево, замок, море — отвечают на тап. Детали красятся «в тон» сердцу (`PALS` в `heart.ts`: акцент, камень, металл — на жёлтом серебро, румянец), в каждом разделе сначала 3–4 простых базовых варианта, потом необычные; у каждого варианта своя реакция (`reactions.ts`). Палочка в ~70% собирает готовый образ из `SETS` (накладывается только на неручные разделы) (`state.ts`: принцесса, котик, море, сладости, фея, единорог, зайка, классика) с 1–2 заменами на базовые, иначе — полный случай. Рот (раздел после носа, `mouth()` в `heart.ts`): по умолчанию улыбка, 10 вариантов (улыбка, до ушей, «о», язычок, клычок, кошачий «ω», губки с помадой в тон — `PALS.lip`, сердечко, зубки зайчика, щербинка); каждый открывается от `L.mouth` (смех, жевание, зевок, песня) и держится в полосе 0.19–0.42 R — не налезает на нос/усы, щёчки и ожерелье; старые сохранения без рта — улыбка, этап сохраняется по id. Обводка деталей на тёплых сердцах — `HALO.mode = 'dark'` (тёмно-винный контур). Ресницы и брови уходят под чёлку, в очках ресницы растут из оправы, подмигивание в реакции не смешивается с морганием. Выбор сохраняется в localStorage; убранные из панели старые варианты по-прежнему рисуются.
  - Уход за сердечком — `src/scenes/heart-dress-up/care/`: `section.ts` — интерфейс раздела `CareSection` (`id`, `state`, `icon`, `optIcon`, `act`, `exit`, `update`; по необходимости `sel`, `enter`, `drawBack/Front/Overlay`, `hit`, `tap`, `heartTap`, `live`, `xform`) и общие помощники (`hp`, `sideX`, `leave/here/stay` для плавного ухода предметов); `index.ts` — реестр `SECTIONS` и внешний API для `main.ts`/`ui.ts`/`icons.ts`; по модулю на раздел (`food.ts`, `bath.ts`, `sleep.ts`), разделы друг друга не импортируют. Единый `careExit()`: смена раздела, палочка и праздник (замечаются в `updateCare`) — всё начатое плавно убирается, без следов в чужом разделе. Новый раздел (доктор, игры): свой модуль + строка в `SECTIONS`, варианты в `careopts.ts`, этап в `STAGES`. Состояние для тестов — `window.__care.food/.bath/.sleep`, сценарии — `tests/heart-care.spec.ts`.
    - Еда (место → нужда → предметы → развязка и след): при входе въезжает столик на ножке с тарелкой (между палочкой и хлопушкой, не под ними), на сердце — слюнявчик в тон (`palOf`); над сердцем облачко-мысль с размытой любимой едой дня (подсказка, ~5 с, тап — «м-м?»; когда нашли — чёткая). Угощение летит из кнопки на тарелку, с тарелки — ко рту, держится ниже рта, откусы сверху; размеры — `FOOD_K` (множитель к 0.17R: конфета/клубника 0.85 … мороженое 1.65, арбуз 1.8); очередь до 3 ждёт на тарелке, лишний тап — кнопка пружинит с «м-м!». Сытость 0..4: голодное облизывается, животик тихо урчит ~раз в 8 с; после 4-го — вздох, сердце круглее, «ик» ×3; дальше ест медленно и смешно (щёки надуты, «ик»), через ~минуту сытость спадает. Стакан — «глык-глык», молочные усы, смывает крошки; салфетка — вытирает крошки и усы, на чистом — щекотно. Следы (`traces` в `section.ts`, переживают смену раздела): хрустящее (печенье, морковка, яблоко) — крошки, кремовое (кекс, мороженое, пончик) — усы из крема; любимая еда пишет `traces.dreams.food` (снится). Таблица «предмет × состояние» (голоден / сыт / испачкан) — в шапке `food.ts`. Любимая еда дня — влюблённые глаза, «смешная еда дня» — гримаса «бе-е» (обе по дате); при выходе — «глык», всё проглочено, столик уезжает. Тесты — `tests/care-food.spec.ts`.
    - Ванна (`care/bath.ts`, тесты `tests/care-bath.spec.ts`) — по модели «место → нужда → предметы → развязка». Место: ванна на золотых ножках въезжает снизу, сердце сидит в воде нижней третью (вода с бликами и кругами); ванна сужается, чтобы не залезать на палочку, хлопушку и за край области. При выходе вода уходит водоворотом, мокрое сердце отряхивается, как щенок (~2.2 Гц), ванна уезжает (уточка — в ней); палочка и праздник убирают ванну сразу. Нужда «чистота»: если сердце не мылось 150 с — 3–5 пятнышек (пыль, клякса краски, следы лапок), крошки и кремовые усы еды из `traces` становятся пятнышками; чистое — пятен нет, купание просто игра; сердце время от времени смотрит на пятнышко, оно подмигивает. Пятнышки и блеск лежат в общих `traces.spots` / `traces.glow` и видны во всех разделах. Состояния: сухое, мокрое (капельки сползают, блики), в пене. Предметы: пена — 3 стадии (шапки по телу и пена на воде → пенная причёска → борода и усы, дальше — ещё пены и пузыри); душ мочит, наполняет ванну, смывает пену сверху вниз и пятна; губка обходит пятнышки и оттирает (на сухом — со скрипом наполовину, без пятен — щекотка), на мокром взбивает пену; полотенце выключает душ и вытирает, на сухом — «ку-ку»; уточка плавает, тап — брызги на сердце (мокрое) и снится сердцу (`traces.dreams.duck`); пузыри поднимаются из воды; слив — водоворот уносит пену и пузыри, выключает душ, пустой — «чпок». Тап по воде — плюх, по стенке — «дзынь», пальцем по пятну — оттирает (на сухом чуть-чуть). Развязка: чисто и сухо после мокрого — звёздочки блеска ~90 с, и в других разделах. Лейка 0.22R, губка 0.24R, уточка 0.28R.
    - Сон (`care/sleep.ts`, тесты — `tests/care-sleep.spec.ts`), модель «место → нужда → предметы → развязка»: при входе вечер (затемнение ~0.25) и кроватка-подушка под сердцем, сердце зевает; при выходе всё уезжает. Сонливость 0..1 копят уютные предметы (одеяло +0.3, мишка +0.2, шкатулка +0.3, ночник +0.2 — один раз за вечер, плюс понемногу, пока рядом): веки опускаются, зевки чаще, при ≥0.8 засыпает само; выспавшееся копит вдвое медленнее. Предметы — «друзья» до выхода, повторный тап по кнопке = тап по предмету: луна — укладывает / по спящему подмигивает с неба и показывает облачко-сон (картинки из `traces.dreams`: любимая еда, уточка, мишка, звёздочки — по кругу); одеяло (поверх мишки и шкатулки, крутится с сердцем) — хихикает / подоткнуть, бормочет; мишка (справа у кончика) — обнимашки / спит вместе и прижимается; ночник — тап меняет цвет, ночью он единственный свет; шкатулка (слева у кончика) — единственная играет колыбельную, во сне тише. Солнышко — утро по шагам ~3.3 с: ночь светлеет → шкатулка закрывается → ночник уезжает → сердце потягивается, одеяло сползает → мишка машет и уходит с кроваткой → солнышко уплывает за край; тап по солнышку — смех, утро не затягивает. Выход из сна — тихое пробуждение без солнышка. Поспал ≥2 с — след «выспалось» (`traces.rested`, ~60 с, переживает смену раздела): глаза блестят, сердце пружинит.
